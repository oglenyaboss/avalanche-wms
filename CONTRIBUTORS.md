# Contributors

**avalanche-wms** started as HSE MIEM university project **#2340** — a
blockchain-backed Warehouse Management System with an auditable, on-chain
history of warehouse operations — and is maintained by the original team.

Thanks to everyone who built it 🙌

## Adding yourself

This project is continuing development beyond the university defense — new
contributions are welcome. To update or correct your entry, edit this file and
commit directly to `main` (or open a pull request). Editing this file is also a
quick way to make sure your earlier commits get credited on your GitHub profile.
