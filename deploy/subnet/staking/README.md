# Staking-креды — ТОЛЬКО ДЛЯ ТЕСТОВ, НЕ СЕКРЕТЫ

Эти три файла — **публичные, общеизвестные креды «staker1» локальной сети Avalanche**
(subject `O=Avalabs, CN=ava`, `NodeID-7Xhw2mDxuDS44j42TCB6U5579esbSt3Lg`). Они лежат в
исходниках avalanchego (`staking/local/`) и зашиты в genesis локальной сети как
единственный валидатор primary-сети.

- `staker.crt` / `staker.key` — TLS-идентичность, фиксирующая NodeID узла так, чтобы он
  совпадал с валидатором в `../network-genesis.json` (network-id 1337).
- `signer.key` — 32-байтный BLS-ключ подписи этого валидатора.

**Они закоммичены намеренно.** Это одноразовый локальный воспроизводимый стенд, защищать
здесь нечего. Не переноси этот подход ни на какую не-локальную сеть — настоящий валидатор
обязан генерировать собственные приватные staking-ключи.
